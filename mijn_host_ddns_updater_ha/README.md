# Mijn.host DDNS Updater for Home Assistant

Home Assistant App wrapping the dependency-free Mijn.host DDNS updater.

## Install

1. Add this repository URL to the Home Assistant App store:
   `https://github.com/MarQuez-Mr/mijn_host_dns_updater_ha`
2. Install `Mijn.host DDNS Updater`.
3. Enter Mijn.host API key, domain, record names, and interval.
4. Start the App.

The App updates A and AAAA records using the current public IP addresses.
